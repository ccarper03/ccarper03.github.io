# Guide build sources

As of October 2026, the live HTML pages in `/guides/` are the source of truth. They have had brand-neutral,
stay-in-my-lane and evergreen edits that these Markdown files and `build_guides.py` don't fully reflect.
Don't regenerate the guides from here without syncing these files to the live pages first.

Evergreen rule for any new content: keep what only changes if something big happens. Anything that changes
on a schedule or by someone's decision (stats, prices, program amounts, build times, features lists, HOA
rules, bus routes) gets a high-level answer plus where to get the current one.
